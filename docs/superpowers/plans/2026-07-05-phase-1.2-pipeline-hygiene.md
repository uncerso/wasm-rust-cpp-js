# Phase 1.2 pipeline-hygiene Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Закрыть четыре pipeline-/reporter-hygiene пункта одной пачкой: correctness-fail surfacing (C), hashmap_string dup-key fix (D), emscripten wasm-opt унификация (A), perf shape_dispatch coverage (B).

**Architecture:** Четыре независимых по коду задачи. C добавляет общий предикат `isCorrectnessFailure` в result-schema + сигналит фейл из обоих раннеров/матрицы. D правит cpp-исходник + ре-бенчит. A удаляет inline wasm-opt из emscripten-скриптов. B перерабатывает shape_dispatch-виджет в reporter'е (сетка хитмапов + 4 detail-таблицы).

**Tech Stack:** TypeScript (tsx-оркестраторы + reporter, ESM, vitest), bash build-скрипты, wasi-sdk-25 clang / emscripten, C++23, binaryen-129 `wasm-opt`.

**Spec:** `docs/superpowers/specs/2026-07-05-phase-1.2-pipeline-hygiene-design.md`

## Global Constraints

- **TS:** 4-space indent, double quotes, semicolons, trailing comma (multiline), `curly: all`, `verbatimModuleSyntax` + strict. ESLint flat config enforces.
- **Схема `BenchResult`:** менять только через `packages/result-schema`. Новый предикат — там же.
- **`wasm-opt`:** только pinned binaryen-129 через `wasmOptPath()`; всякий вызов с `--enable-bulk-memory --enable-nontrapping-float-to-int`. (A **удаляет** вызовы, не добавляет.)
- **Never edit** авто-генерённые `**/glue.mjs` / `**/glue.js`.
- **Sandbox:** `pnpm build:*` / `smoke` / бенч — с `dangerouslyDisableSandbox: true` (tsx-pipe bind). Чистые `typecheck` / `test` / `lint:*` — в sandbox.
- **Commits:** `--no-gpg-sign`. Push/PR — действие пользователя.

## Execution Protocol

**Routing (hybrid inline/subagent):**
- **Task 1 (C)** — `[I]` inline: 3 файла + unit-тест, связная логика, держится в контексте.

- **Task 3 (A)** — `[I]` inline: 8 near-identical удалений + grep-верификация + build; тривиально, но грепать ВСЕ 8 (siblings дрейфуют).
- **Task 4 (B)** — `[S]` subagent: крупная самодостаточная reporter-переработка; дать субагенту ВЕСЬ gate-набор (typecheck+lint+test) + спеку + интерфейсы ниже.

**Static break-points (рекомендовать `/finish-session`, решает пользователь):**

**Per-task break-check:** после каждой задачи — gates зелёные? незапланированные правки? если pre-identified риск (A size-регресс / D дельта / C ложные срабатывания) сработал — эскалировать пользователю, не применять «молча».

```ts
import type { BenchResult } from "./schema.js";

/**
 * A case is a correctness failure when the reference checksum did not match
 * (`correctnessFailed`) or validation did not pass. Neither runner throws on
 * mismatch — they write the result with the flag set — so callers use this to
 * surface silent correctness fails (failures.txt + non-zero exit).
 */
export function isCorrectnessFailure(r: BenchResult): boolean {
    return r.quality.correctnessFailed || !r.quality.validated;
}
```
